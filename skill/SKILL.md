# 微软拼音个性化词库生成器

## 0. 目标与原则（先读这段）

**唯一目的：产出"这个用户最适用的 20,000 条词库"。数据源只是手段。**

四条原则：

1. **能力自适应** —— 有下载/抓取能力就自己抓；**抓不到不等于做不了**：产出"取词清单"交接给用户、或其他 agent（可能装着下载器类技能）去取。**换个执行者能拿到的东西，就不要放弃那个词汇域。**
2. **每个词都要能说出处** —— 标注 provenance：`verified-open`（开放数据，许可明确）/ `wiki`（维基类 API）/ `agent-curated`（agent 整理，**必须提示用户确认**）。
3. **追"命中真实输入"，不追"总量"** —— 额度只有 2 万，宁可少一个域也要保证入选的是用户真会打的词。
4. **闭环** —— 必须给出复测清单，用行为数据验证，而不是自称"已优化"。

## 0.1 四条硬约束（本机实测，违反则全白做）

1. **上限 20,000 条，由 IME 强制**：构造合法 25,000 条容器导入后仍被截回 20,000。任务是**取舍**，不是堆量。
2. **只有官方导入可靠**：直接替换词库文件会被 IME 回灌覆盖（实测写入 19,900 条后重合度掉到 6.9%）。
3. **只收纯中文 2–15 字**：含字母/数字/空格的词会被 IME 过滤。所以 `BMW`、`R1200GS`、`K8s` 不收；要收它们的中文名与中文绰号（如"水鸟""金翼")。
4. **通用词基本无效**：内置核心词库覆盖面极广（27 词分层采样 26 命中，含低频词、县区地名、人名、4 字词）。价值在**长尾专名 + 行业术语 + 品牌/圈层黑话 + 新词 + 私有词**。

## 1. 采集画像（维度不设死）

- 用**对话**，一轮 2–3 题，允许跳过；每轮**复述已获取信息**并**主动追问派生问题**。
- 可问维度（**示例，不是封闭列表**，按需扩展）：职业与细分方向 / 常驻与常去地点 / 兴趣爱好及程度 / 常混的社群 / 常用设备与品牌 / 家庭角色 / 主要输入场景 / 年龄段 / 常打的方言词 / 有没有自己的词表文件。
- 输出 `profile.json`，**本地保存，不上传**。

## 2. 画像 → 词汇域推理（核心增值）

不要做字段死映射。对每个画像事实走三步：

```
① 场景（我在什么情境下打字）→ ② 输入对象（我会说出哪些名词/短语）→ ③ 词形（中文写法、别名、绰号、全称、简称）
```

示例推理链（照此模式自行展开）：

| 画像事实 | 场景 | 输入对象 | 词形举例 |
|---|---|---|---|
| 摩旅、常去陌生城市 | 找路、发定位、写游记 | 城市/区县/**乡镇街道**/景区/服务区 | 锦官驿街道、川主寺镇、上燃姑乡 |
| 机车 | 聊车、买装备、写评测 | 品牌、车型、**车型绰号**、装备、黑话 | 品牌中文名（钱江/无极/春风/本田/杜卡迪…）、绰号（水鸟/金翼/小忍者）、装备（边箱/骑行雨衣）、黑话（压弯/跑山/摩友） |
| 程序员 | 写文档、聊方案 | 技术术语、框架中文名、岗位黑话 | 时间复杂度、容器编排、灰度发布、埋点 |
| 40 岁 | 聊天、看点 | 年代影视剧名、演员、老梗 | 剧名、人名 |
| 任何画像 | 日常沟通 | 新词/网络流行语/黑话 | 年度流行语、圈层用语 |

**输出"词汇域清单"**：`域 / 目标条数 / 优先度 / 检索关键词 / 已知合适词源`。后续找词、打分、配额都以它为依据。

## 3. 词源获取（能力自适应）

### 3.1 A 层：已验证词库（直接用，许可已核对）

| 词源 | 内容 | 许可 | 地址 |
|---|---|---|---|
| jieba | 通用词频 33.7 万 | MIT | `https://raw.githubusercontent.com/fxsjy/jieba/master/jieba/dict.txt` |
| THUOCL | 11 个领域（IT/医学/法律/财经/饮食/汽车/动物/地名/历史名人/诗词/成语），带词频 | MIT | `https://raw.githubusercontent.com/thunlp/THUOCL/master/data/THUOCL_<name>.txt` |
| chinese-xinhua | 成语 30,895 / 词语 264,434 | MIT | `.../pwxcoo/chinese-xinhua/master/data/idiom.json`、`ci.json` |
| 行政区划（乡级/村级） | 乡镇街道 41,352；村级更大 | **WTFPL** | `https://raw.githubusercontent.com/modood/Administrative-divisions-of-China/master/dist/streets.json`（`villages.json` 84MB） |
| 官方年度流行语 | 国家语言资源监测与研究中心"年度十大网络流行语" | 公开 | 新华网每年 12 月发布，检索即得 |
| `skill/wordlists/*.txt` | 本仓库附带的 agent 整理清单（机车/游戏/黑话） | 本项目 MIT | 直接用，但**记得标注需用户确认** |

### 3.2 B 层：自己去找（画像派生的词往往不在现成词库里）

- **优先开放接口/数据集**：WikiData SPARQL（按中文标签取实体名，CC0）、政府公开数据（区划代码）、GitHub 开放词表、维基百科分类 API（`action=query&list=categorymembers`，可用但稀疏）。
- **检索式模板**（拿去搜）：
  `<领域> 术语 大全` · `<品牌> 车型 中文名 列表` · `<车型> 绰号 外号 叫什么` · `<城市> 街道/乡镇 名录` · `<年份> 网络流行语 年度` · `<圈层> 黑话 用语` · `site:zh.wikipedia.org <主题> 列表`
- 抓网页前确认站点条款与 robots；只取**公开非个人**数据；不绕过反爬；优先 API。

### 3.3 C 层：抓不到就交接（**不要因此放弃词汇域**）

把你的抓取失败转化成一份 **取词清单** `fetch-plan.md`，交给用户或另一个 agent（它可能有下载器/浏览器类技能）：

```
## 取词单：<词汇域>
- 为什么要：<画像依据>
- 检索式：<可直接粘贴的查询>
- 目标来源：<站点/API/文件名>
- 期望格式：一行一词，UTF-8，纯中文，2-15 字（含字母/数字的词不要）
- 落盘路径：cache/<source-id>/raw.txt
- 许可要求：能说出处即可；不确定就标注"许可待核实"
- 备注：<已知反爬/需要登录等情况>
```

**同时给出降级方案**（保证这一次仍能出词包）：
1. 用 `skill/wordlists/` 里的 agent 整理清单顶上（标注 `agent-curated`）；
2. 或把该域配额转给能拿到的域（把域清单与配额一起写进报告，说明取舍原因）；
3. 在报告的"下次可改进项"里明确列出待补的域与取词单位置。

### 3.4 D 层：用户私有词
最值的一类。有就让用户给（一行一词，不用注音），优先占位。

## 4. 校验（每个源都要过，不过就丢弃并记录原因）

```
下载/获取 → 可达性 → 识别编码(UTF-8/GBK/UTF-16) → 解析出词条 → 抽样 20 条人工看 → 统计纯中文比例
```
丢弃条件：解析不出词条 / 纯中文比例 < 80% / 许可不明 / 与内置已知词重复率 > 90%。
把结果写回 `skill/sources.psd1` 的 `Verified` 与 `Note`。缓存到 `cache/<source-id>/`（含 `manifest.json`：url/sha256/size/license/downloaded_at/provenance）。

## 5. 去重 → 剔除内置 → 打分 → 配额 → 截断

1. 过滤：纯中文、2–15 字
2. **剔除内置已有词**：跑 `python tools/extract_builtin_words.py` 生成本机内置词表（专业词典 + 内置短语），命中即丢弃
3. 去重合并（同词多源 → 最高分并合并类别）
4. 打分：`score = base_weight × category_weight(画像) × length_bonus`
   `length_bonus`：2 字 ×0.6（IME 常能自动拼对）｜3–4 字 ×1.0｜5–6 字 ×1.2｜7–8 字 ×1.1
5. 类别配额后截断到 20,000；参考比例：行业术语 25% / 长尾专名 15% / 地名 15% / 通用 20% / 品牌·圈层 10% / 长短语 10% / 成语 ≤5%（内置覆盖接近 100%，给多了纯浪费）

## 6. 交付物（缺一不可）

| 文件 | 内容 |
|---|---|
| `<name>.mspinyin.dat` | 词库容器；自检 magic `55 AA 88 81`、`count@0x0C`、大小 = `ceil((9228+60N)/1024)×1024` |
| `<name>-report.md` | 每个域的来源/许可/provenance/条数、被剔除数、**取舍说明与下次可改进项** |
| `<name>-retest.md` | 复测清单（每类 3 条，带拼音），导入前后各打一遍 |
| `sources-manifest.json` | 源清单：url/license/sha256/provenance |
| `fetch-plan.md` | **仅当有域没抓到**：取词单（§3.3 格式） |

## 7. 官方导入（唯一可靠路径）

设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → ⋯ → 语言选项 → 微软拼音 → 词库和自学习 → **导入** → 选择 `.dat`

## 8. 复测与调参

导入前后各打同一份清单 → 命中率写回报告 → 调权重与配额（没命中的域加配额；命中率接近 100% 的域减配额，把额度让给别人）。

## 9. 注册表与扩展

见 `skill/sources.psd1`：`Sources`（已验证）+ `Discovery`（检索式/开放接口/画像→去哪找）+ `ValidationChecklist` + `ExcludeBuiltin` + `QuotaRatio`。
**允许 agent 自己往注册表加源**，加完跑 §4 校验并把结果写回 `Verified`。

## 10. 质量红线

- 不承诺突破 20,000 条（IME 强制）
- 不把通用高频词当主力
- 不直写词库文件（会被回灌）
- 不上传画像与私有词表
- 不抓个人隐私数据、不绕过站点反爬与条款
- 收录任何数据都要能说出**来源与许可**；`agent-curated` 的内容必须提示用户确认
