# 数据流与隐私

## 一、微软拼音默认会往外送什么

| 通道 | 内容 | 说明 |
|---|---|---|
| **云候选**（`Enable Cloud Candidate`） | 正在输入的拼音/上下文 | 开则**输入内容出网**，关则纯本地 |
| 诊断数据（Windows 遥测） | 使用统计 | 系统级开关：设置 → 隐私和安全性 → 诊断和反馈 |
| 微软账户漫游 | 词库/语言偏好 | 数据目录里的 `OnlineRoaming\` 是漫游通道；未登录/未开同步时为空 |
| 本地自学习 | 你的选词记录 | **纯本地**文件（`ChsPinyinUDL*.dat`），不出网 |

关键：**"要智能"和"要隐私"不冲突** —— 云候选可以关掉，本地自学习与词库导入仍然有效。

## 二、本项目做了什么

1. `Set-PinyinPrivacy.ps1` 默认关闭 `Enable Cloud Candidate`，保留本地自学习与动态词频；改动前导出 `.reg` 快照，`-Restore` 一条命令回滚
2. 词库只在**本机**处理：取源 → 选词 → 转容器 → 你手动导入
3. `Backup-PinyinData.ps1` 备份词库与注册表（含 SHA-256）；`Restore-PinyinData.ps1` 还原

顺手建议：
- 设置 → 账户 → Windows 备份 → "记住我的首选项"关闭（避免词库/偏好随账户上云）
- 设置 → 隐私和安全性 → 诊断和反馈 → 发送可选诊断数据 = 关

## 三、画像与私有词表

- 画像（`skill/profile.json`）与私有词表**只存在本地**，本仓库的任何脚本都不会上传
- 仓库的 `.gitignore` 已排除 `cache/`、`out/`、`skill/profile.json`、`config/config.psd1`
- 发布/分享本项目时，**不要**提交 `cache/` 与 `out/`（里面是你的词表与来源数据）

## 四、数据源的许可

我们只收录许可明确的来源（MIT / WTFPL / CC0 / CC BY-SA / 公共领域），并在 `skill/sources.psd1` 与每份报告里标注出处。
`agent-curated`（agent 整理）的词表会明确提示用户确认。

## 五、自证（可选）

1. 看进程网络活动：资源监视器（`resmon`）→ 网络 → 观察 `ChsIME.exe` 是否有持续连接
2. 抓包复核：Wireshark 过滤 `tcp.port == 443`，打字时对关闭云候选前后做对比
3. 词库文件是本地的：`%APPDATA%\Microsoft\InputMethod\Chs\` 下的 `.dat` 就是你的词库，随时可备份

## 六、边界

- 本项目只改**你自己机器**上的本地配置与文件
- `cache/`、`out/` 里可能包含你的词表，**不要提交或分享**
- 关闭云候选后候选词会变少 —— 这是设计取舍，不是缺陷
